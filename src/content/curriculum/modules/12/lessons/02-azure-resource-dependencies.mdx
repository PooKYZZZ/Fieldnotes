<ConceptSection layout="split">
  <div className="learning-concept-copy">
Azure groups resources for lifecycle and governance. A VM depends on network interfaces, disks, network security
rules and sometimes public addresses; deleting only the VM may leave billable resources. Learn the dependency
graph before creating anything. For a small lab, sketch the links before provisioning:

```text
VM ── managed disk
 ├── network interface ── subnet / network security group
 └── optional public IP
```

Each resource can have a separate lifecycle, and delete behavior depends on its configuration. Before cleanup,
inventory what was created, check each resource's current deletion options, then verify the resource group and
billing view after removal. “The VM is gone” does not establish that its disk, address or other resources were
removed.
