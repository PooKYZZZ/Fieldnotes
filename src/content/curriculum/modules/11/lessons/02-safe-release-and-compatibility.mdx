<ConceptSection layout="split">
  <div className="learning-concept-copy">
Before changing a service, check health, persistent data, configuration and external dependencies. A code rollback
may not undo a database schema migration or a message already sent to another system. Backward-compatible
expand/contract changes allow old and new code to coexist during a rollout: add a compatible field, deploy code that
supports both shapes, migrate usage, then remove the old field in a later release. This is a pattern, not a guarantee;
test it against the application's real data operations.
