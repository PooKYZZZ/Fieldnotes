Linux presents one directory tree rooted at `/`. A mounted disk or network filesystem appears at a directory in
that tree, so the path does not reveal which device stores the bytes. An absolute path starts at `/`; a relative path
starts from the process's current working directory. `pwd` answers where a shell is operating, while `find` and
`stat` help inspect files and metadata.
