<ConceptSection layout="split">
  <div className="learning-concept-copy">
Commands normally return status `0` for success and nonzero for a failure or special condition. Terminal text is
useful, but scripts should also check status before acting on output. Package managers track installed versions,
dependencies and repository origin. Copying a binary into a directory does not update that inventory, so the system
cannot reliably upgrade, verify or remove it later.
