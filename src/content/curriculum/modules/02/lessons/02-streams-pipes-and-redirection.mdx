<ConceptSection layout="split">
  <div className="learning-concept-copy">
Each process can read standard input and write standard output and standard error. A pipe connects one process's
output to the next process's input; redirection sends a stream to a file or another destination. The shell opens
redirection targets before starting the command, so `>` can truncate an existing file even if the command later
fails. Use a new report path or append with `>>` when that is intended.
