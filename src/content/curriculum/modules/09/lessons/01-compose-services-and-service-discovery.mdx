<ConceptSection layout="split">
  <div className="learning-concept-copy">
A Compose project defines related services, networks, volumes and runtime settings. Services on a shared network
can resolve each other by service name, so an API can connect to `db:5432` without publishing the database port to
the host. Publish only the service ports that a host user needs to reach. A published port is a network boundary,
not an authentication mechanism.
