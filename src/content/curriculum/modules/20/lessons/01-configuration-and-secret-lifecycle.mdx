<ConceptSection layout="split">
  <div className="learning-concept-copy">
    <p>Configuration describes how an application behaves in an environment; a secret is configuration whose disclosure could grant access or reveal protected data. Keep ordinary defaults in a documented template and put real credentials in an appropriate secret store. Environment variables are convenient but can appear in process inspection, crash reports or debug output. Avoid printing them and never bake them into an image layer.</p>
    <p>A secret has an owner, scope, storage location, expiration or rotation path, and revocation procedure. If it is published, remove its access by rotating or revoking it; deleting the visible file does not remove it from Git history or copies already fetched.</p>
