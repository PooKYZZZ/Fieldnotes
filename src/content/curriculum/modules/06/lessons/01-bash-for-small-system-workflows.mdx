<ConceptSection layout="split">
  <div className="learning-concept-copy">
Bash is useful when a task composes existing command-line tools. Variables, functions, tests and pipes can make a
short procedure repeatable, but the shell expands values before invoking each program. Quote variables that should
remain one argument, and pass untrusted input as data rather than building a command string from it.

`set -o pipefail` helps a pipeline report a nonzero status from an earlier command. It is not a replacement for
designing expected failure branches: commands such as `grep` commonly return a nonzero result when no match exists.
Preview target files before changing them and prefer a read-only default.
