A workflow file declares events, jobs and steps. An event such as a pull request schedules a runner; steps execute
commands or actions in that job's environment. Separate jobs can use different runners and do not automatically
share files. Use artifacts when one job needs a specific output from another. Cache dependencies to reduce install
time, but do not confuse a cache with a verified build artifact.
