<ConceptSection layout="split">
  <div className="learning-concept-copy">
Tests, lint, type checks, integration tests and container builds catch different failures. A green status applies to
the revision and workflow that ran; it does not prove a later commit or deployed environment is correct. When a run
fails, locate the first causal error and compare the exact commit, event and environment before rerunning.

An artifact should have a clear name, retention policy and relationship to the source revision. Preserve useful
reports while avoiding credentials, personal data and debug dumps that reveal secrets.
