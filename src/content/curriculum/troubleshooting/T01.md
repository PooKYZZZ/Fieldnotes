# DNS versus HTTP

## Observation

Your laptop resolves the server name, but the API request times out.

## Investigation

Collect hostname resolution, destination IP, route, listening port and firewall evidence.

## Safety constraint

Work only on disposable resources or services you own, and record initial evidence before applying a
fix.

## Hint

Avoid changing DNS just because a browser displays a generic network error.

## Completion evidence

Provide a cause hypothesis, evidence that differentiates it from another possible cause, a minimal fix
and a repeatable verification step.
