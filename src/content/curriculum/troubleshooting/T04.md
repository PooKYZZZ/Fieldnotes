# Missing Compose data

## Observation

A database appears empty after you recreate the stack.

## Investigation

Identify the storage mount, old volume, Compose project name and database initialization
behavior.

## Safety constraint

Work only on disposable resources or services you own, and record initial evidence before applying a
fix.

## Hint

Different project names can create different volume names.

## Completion evidence

Provide a cause hypothesis, evidence that differentiates it from another possible cause, a minimal fix
and a repeatable verification step.
