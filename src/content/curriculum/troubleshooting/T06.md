# Secret exposure

## Observation

A dummy token unexpectedly appears in a build log.

## Investigation

Trace how it entered the job and identify all places it may persist; plan revocation for real
secrets.

## Safety constraint

Work only on disposable resources or services you own, and record initial evidence before applying a
fix.

## Hint

Deleting a single line from Git history does not automatically revoke a leaked credential.

## Completion evidence

Provide a cause hypothesis, evidence that differentiates it from another possible cause, a minimal fix
and a repeatable verification step.
