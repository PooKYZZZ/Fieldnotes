# Cloud access denied

## Observation

SSH times out, but the Azure VM reports running.

## Investigation

Check target IP, NSG, host firewall, SSH listener and routes before changing permissions.

## Safety constraint

Work only on disposable resources or services you own, and record initial evidence before applying a
fix.

## Hint

Control-plane login permission and guest SSH login are different.

## Completion evidence

Provide a cause hypothesis, evidence that differentiates it from another possible cause, a minimal fix
and a repeatable verification step.
