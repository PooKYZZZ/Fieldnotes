# Missing monitoring data

## Observation

Your Grafana chart is blank but the API responds normally.

## Investigation

1. Confirm the dashboard time range and that it covers the period when the lab service should have been scraped.
2. In the monitoring system, check the target's scrape health and last error before changing a dashboard query. For a local Prometheus-compatible endpoint, the `up` series distinguishes a successful scrape (`1`) from a failed scrape (`0`) for that target.
3. Check the service's local `/metrics` endpoint and compare its metric names and labels with the dashboard query. Use a bounded lab label set; do not add a user ID or raw URL to make a query match.
4. Verify the target address, network path, scrape interval and application metrics exporter. A normal API response does not prove that the scraper can reach the metrics endpoint.
5. Change one lab target or selector at a time, then confirm both the target health and query result over a fresh scrape interval.

## Safety constraint

Work only on disposable resources or services you own, and record initial evidence before applying a
fix.

## Hint

A blank dashboard is a telemetry problem until proven otherwise.

## Completion evidence

Record target scrape health and last error, the relevant metric name/labels and dashboard window, the selector or target correction, and a fresh successful query. Keep target addresses sanitized.
