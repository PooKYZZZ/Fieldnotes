# Missing monitoring data

## Observation

Your Grafana chart is blank but the API responds normally.

## Investigation

Inspect scraper target health, endpoint metrics, time range and query label selectors.

## Safety constraint

Work only on disposable resources or services you own, and record initial evidence before applying a
fix.

## Hint

A blank dashboard is a telemetry problem until proven otherwise.

## Completion evidence

Provide a cause hypothesis, evidence that differentiates it from another possible cause, a minimal fix
and a repeatable verification step.
