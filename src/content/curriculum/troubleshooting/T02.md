# NGINX returns 502

## Observation

NGINX serves static files but proxying /api fails after an app update.

## Investigation

Check upstream process, bind address, proxy target, service logs and last known-good config.

## Safety constraint

Work only on disposable resources or services you own, and record initial evidence before applying a
fix.

## Hint

A restart is an experiment, not a diagnosis.


## Completion evidence

Provide a cause hypothesis, evidence that differentiates it from another possible cause, a minimal fix
and a repeatable verification step.
