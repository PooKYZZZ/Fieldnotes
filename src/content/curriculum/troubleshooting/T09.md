# Ansible repeated changes

## Observation

The second run still reports several changed tasks.

## Investigation

Identify which tasks are non-idempotent or use blind shell commands.

## Safety constraint

Work only on disposable resources or services you own, and record initial evidence before applying a
fix.

## Hint

Repeated changes are not necessarily harmless.

## Completion evidence

Provide a cause hypothesis, evidence that differentiates it from another possible cause, a minimal fix
and a repeatable verification step.
