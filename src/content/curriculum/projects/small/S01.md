# Log explorer

## Problem

Find errors or unusual periods in long service logs

## Requirements

A command-line report that accepts a log file, filters by level/time, counts error types and
handles missing/invalid data

## Deliverables

Small test fixture; CLI help; example sanitized output

## Acceptance criteria

Correct counts on known input; useful error on malformed input; no private data output

## Likely challenge

Input validation, unexpected state and reproducibility; investigate failure behavior before adding
features.

## Optional extension

Add JSON export or cross-file aggregation
