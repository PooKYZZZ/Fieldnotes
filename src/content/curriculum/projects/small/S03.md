# Service watchdog report

## Problem

Summarize health of services on your own lab machine

## Requirements

Check service status, process restarts, disk usage and endpoint health without forcibly
restarting anything

## Deliverables

Script, test cases and a daily report example


## Acceptance criteria

Returns nonzero on a failed check and reports a useful reason

## Likely challenge

Input validation, unexpected state and reproducibility; investigate failure behavior before adding
features.

## Optional extension

Add opt-in notification with rate limits

Linux Foundation - free introduction to Linux. See corresponding module in 01-03 and activity in
