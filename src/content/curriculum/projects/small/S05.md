# Backup verifier

## Problem

Check if a backup can actually be used

## Requirements

Produce a snapshot of disposable test data, restore to a fresh location and compare
known records

## Deliverables

Backup/restore checklist with automated verification evidence

## Acceptance criteria

Restored sample data matches the pre-backup fixture; never touches live data

## Likely challenge

Input validation, unexpected state and reproducibility; investigate failure behavior before adding
features.

## Optional extension

Add retention rules and integrity hashes
