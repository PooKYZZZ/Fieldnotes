# Metrics and alert probe

## Problem

See whether monitoring catches a known failure

## Requirements

Publish simple metrics and simulate a service outage

## Deliverables

Dashboard screenshot, rule and response note

## Acceptance criteria

Alert fires on outage, resolves on recovery, no credentials exposed

## Likely challenge

Input validation, unexpected state and reproducibility; investigate failure behavior before adding
features.

## Optional extension

Compare alert duration with actual observed downtime

## Technical reference

Prometheus - Getting started. See corresponding module in 01-03 and activity in 04_Activities_and_Practice.pdf.
