# CI failure gallery

## Problem

Learn how real pipelines fail rather than just passing

## Requirements

Create small intentional failures for lint, test, missing env and Docker build steps

## Deliverables

Repository with branches or tags documenting each case

## Acceptance criteria

Every failure has an identifiable earliest useful log and verified fix

## Likely challenge

Input validation, unexpected state and reproducibility; investigate failure behavior before adding
features.


## Optional extension

Add a matrix test with two Python versions

## Technical reference

GitHub Actions - Quickstart. See corresponding module in 01-03 and activity in 04_Activities_and_Practice.pdf.
