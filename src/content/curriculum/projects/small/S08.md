# Terraform cleanup checker

## Problem

Prevent leftover cloud resources and surprise charges

## Requirements

Enumerate resources in a disposable lab group and record expected cleanup outcomes

## Deliverables

Resource manifest and destroy/runbook checklist

## Acceptance criteria

Inventory empty after cleanup; any retained resources are documented and intentional

## Likely challenge

Input validation, unexpected state and reproducibility; investigate failure behavior before adding
features.

## Optional extension

Add tag-based inventory reporting

HashiCorp Terraform - Docker tutorials. See corresponding module in 01-03 and activity in
