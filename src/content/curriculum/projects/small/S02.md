# Network diagnostic notebook

## Problem

Avoid random fixes when a hostname or port fails

## Requirements

Collect name resolution, route, TCP connect, TLS and HTTP results for user-approved
targets

## Deliverables

Read-only diagnostic checklist, diagram and sample report

## Acceptance criteria

Clearly distinguishes DNS, transport, TLS and HTTP; no intrusive scanning

## Likely challenge

Input validation, unexpected state and reproducibility; investigate failure behavior before adding
features.

## Optional extension

Support IPv6 or configurable timeout

Cisco Networking Academy. See corresponding module in 01-03 and activity in 04_Activities_and_Practice.pdf.
