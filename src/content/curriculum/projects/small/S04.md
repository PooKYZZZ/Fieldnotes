# Compose configuration validator

## Problem

Catch configuration drift before running a stack

## Requirements

Check required files and variables, duplicate published ports and missing
persistent-volume declarations

## Deliverables

Validator script or documented preflight command

## Acceptance criteria

Detects at least three known invalid configurations with clear messages

## Likely challenge

Input validation, unexpected state and reproducibility; investigate failure behavior before adding
features.

## Optional extension

Add local smoke tests after startup

Docker - Get Started. See corresponding module in 01-03 and activity in 04_Activities_and_Practice.pdf.
